# FARU — путешествия только на Мальдивы

Статичный одностраничный сайт (один файл `index.html`, без сборки).

Концепция: «Мальдивы — это 1 192 острова. Ваш — один». Faru на дивехи — «риф».
Сайт помогает выбрать не отель, а остров: подбор курорта по параметрам,
схема атоллов с севера на юг, календарь муссонов (Iruvai / Hulhangu),
объяснение трансферов (катер, гидросамолёт, внутренний рейс) и форма заявки.

## Что поправить перед запуском
- Контакты — объект `CONTACT` в начале `<script>`: телефон, почта и номер
  WhatsApp в международном формате без `+` (например `77001234567`) —
  тогда в форме появится кнопка «Открыть WhatsApp» с готовым текстом заявки.
- Курорты — массив `RESORTS`, атоллы — `ATOLLS`. Данные ориентировочные
  (время трансфера, уровень цен, качество рифа 1–3) — проверить и дополнить.
- Название FARU — рабочее, меняется поиском по файлу.

## Публикация
Любой статичный хостинг: GitHub Pages (отдельный репозиторий), Netlify,
Cloudflare Pages. Свой домен подключается там же.
