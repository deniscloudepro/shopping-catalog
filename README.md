# Каталог личных покупок

Google Таблица — единственное хранилище (нет своей БД, нет своего сервера
для сайта). Три способа добавить товар:

1. **Приложение Claude на телефоне** — если в Claude подключён коннектор
   Google Sheets/Drive, можно прямо в чате кинуть ссылку/HTML товара и
   попросить Claude добавить строку в таблицу. Настраивается в самом
   приложении Claude (Settings → Connectors), не требует ничего из этого
   репозитория.
2. **Telegram-бот** ([apps/bot](apps/bot)) — присылаешь ему ссылку, он сам
   открывает страницу и парсит название/цену/фото. Не работает на сайтах с
   защитой от ботов (Cloudflare и т.п.) — тогда бот попросит ввести данные
   вручную **или** прислать сохранённую страницу: открой товар в браузере
   телефона, «Поделиться → Сохранить» (.mht / .mhtml / .html) и отправь
   файл боту — он достанет название/цену/фото из файла. Фото, присланное
   картинкой, бот сохранить не может (ссылка на файл в Telegram содержит
   токен бота, а таблица публичная) — нужна ссылка на картинку.
3. **Браузерное расширение** ([apps/extension](apps/extension)) —
   открываешь товар в своём браузере, жмёшь иконку расширения. Страница уже
   отрендерена (защита от ботов пройдена самим браузером), расширение
   читает данные прямо из DOM и шлёт их в Google Apps Script (см. ниже).

Сайт-каталог ([docs](docs)) — чистый статичный HTML/CSS/JS без сборки,
как [mysite](https://github.com/deniscloudepro/mysite): читает таблицу
напрямую из браузера через публичный JSON-эндпоинт Google Sheets и
показывает всё плиткой (фото/название/цена/ссылка на оригинал). Лежит в
`/docs`, чтобы GitHub Pages подхватил его без лишней настройки.

## Как это устроено

```
docs/                — статичный сайт-каталог (GitHub Pages source: /docs).
                       index.html + assets/css + assets/js/script.js —
                       никакого фреймворка и сборки, как mysite.
apps/
  bot/               — Telegram-бот (Telegraf). Парсит страницу на сервере;
                       если сайт блокирует запрос — просит ввести данные
                       вручную. Пишет строки прямо в Google Таблицу через
                       сервисный аккаунт.
  extension/         — расширение для Chrome/Chromium. Popup парсит
                       открытую вкладку и шлёт данные в Google Apps Script.
packages/
  scraper/           — серверный парсер title/price/image/site (для бота):
                       сначала JSON-LD Product, потом Open Graph, потом
                       <title>.
  sheets/            — работа с Google Таблицей из Node (для бота):
                       appendItemRow() и listItems().
google-apps-script/
  Code.gs            — код Web App, который принимает POST от расширения и
                       дописывает строку в таблицу. Деплоится вручную в
                       script.google.com (см. ниже) — Node тут не нужен.
```

**Почему так:** изначально была своя БД (Prisma/SQLite) на компе, Sheets —
просто дублирующий лог, а сайт — Next.js на Vercel. Отказались от этого по
двум причинам: (1) комп не всегда включён, а телефон — всегда, поэтому
источником правды стала облачная Google Таблица; (2) GitHub Pages на
бесплатном тарифе не работает с приватными репозиториями, поэтому сайт
пересобрали в чистый статичный HTML без сервера — тогда деплой сводится к
`git push`, без Vercel/аккаунтов на стороне.

## Установка

Нужен Node.js 18+ (для бота).

```bash
npm install
```

### 1. Google Sheets (сервисный аккаунт) — обязательно для бота и расширения

1. Зайди в [Google Cloud Console](https://console.cloud.google.com/), создай
   проект. Если попросит включить двухфакторную аутентификацию на
   Google-аккаунте — сделай это в [настройках безопасности аккаунта](https://myaccount.google.com/security)
   и вернись.
2. Включи **Google Sheets API** (APIs & Services → Library).
3. Создай сервисный аккаунт (APIs & Services → Credentials → Create
   Credentials → Service Account) → Keys → Add Key → JSON, скачай ключ.
4. Из JSON тебе нужны `client_email` и `private_key`.
5. Создай Google Таблицу ([sheets.new](https://sheets.new) — можно пустую,
   код сам создаст вкладку "Items" и заголовки при первой записи). Открой
   доступ на **редактирование** для email из `client_email`.
6. Открой доступ на **чтение по ссылке** («Anyone with the link — Viewer»)
   — так сайт сможет читать таблицу без сервера и без ключа.
7. ID таблицы — часть ссылки: `https://docs.google.com/spreadsheets/d/ЭТОТ_ID/edit`.

### 2. Telegram-бот

Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получишь `BOT_TOKEN`.

### 3. Переменные окружения бота

```bash
cp apps/bot/.env.example apps/bot/.env
```

Впиши: `BOT_TOKEN`, `GOOGLE_SHEETS_ID`, `GOOGLE_SERVICE_ACCOUNT_EMAIL`,
`GOOGLE_PRIVATE_KEY` из шагов выше.

### 4. Сайт (docs/)

Открой [docs/assets/js/script.js](docs/assets/js/script.js), впиши свой
`SHEET_ID` в начале файла (константа `SHEET_ID`). Всё, сайт готов —
никакой сборки не нужно, это просто статичные файлы.

Проверить локально:

```bash
npm run site:dev
```

и открой http://localhost:8000.

### 5. Запуск бота

```bash
npm run bot:dev
```

Пришли боту в Telegram ссылку на любой товар — он появится на сайте
(обнови страницу, сайт читает таблицу при каждом заходе).

### 6. Google Apps Script (принимает данные от расширения)

Раз сайт статичный и своего сервера нет, для приёма POST-запросов от
расширения используется Google Apps Script — бесплатный сервис Google,
привязанный к твоему аккаунту.

1. Сгенерируй ключ (одна и та же строка пойдёт и в `apps/bot/.env` как
   `EXTENSION_API_KEY`, и в скрипт ниже):
   ```bash
   node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
   ```
   Добавь строку `EXTENSION_API_KEY=...` в `apps/bot/.env`.
2. Открой [script.new](https://script.new) — создастся новый Apps Script
   проект.
3. Сотри содержимое редактора, вставь целиком код из
   [google-apps-script/Code.gs](google-apps-script/Code.gs).
4. В начале файла впиши свой `SHEET_ID` и вставь в `API_KEY` тот же ключ,
   что сгенерировал в шаге 1.
5. **Deploy → New deployment** → тип **Web app** → Execute as: *Me*,
   Who has access: *Anyone* → Deploy. Скопируй URL (заканчивается на
   `/exec`).
6. Разреши скрипту доступ к твоей таблице, когда Google спросит
   разрешение при первом деплое.

### 7. Браузерное расширение (для сайтов, которые блокируют бота)

1. Открой `chrome://extensions` (или `edge://extensions`).
2. Включи **Режим разработчика**.
3. **Загрузить распакованное расширение** → выбери папку `apps/extension`.
4. Иконка появится на панели — правой кнопкой → **Параметры**.
5. Впиши:
   - **URL Apps Script Web App** — тот, что скопировал в шаге 6.5 выше.
   - **API-ключ** — тот же `EXTENSION_API_KEY`.
6. Сохрани. Теперь на странице товара жми на иконку расширения,
   проверяй/поправляй название-цену-фото и жми «Добавить в каталог».

Расширение просит доступ ко всем сайтам (`host_permissions`) — сайт
заранее не известен. Не публикуется в Chrome Web Store, работает только у
тебя как «распакованное».

## Деплой сайта (GitHub Pages)

Репозиторий должен быть **публичным** — GitHub Pages для приватных репо
работает только на платных тарифах. В коде секретов нет (приватный ключ
сервисного аккаунта используется только ботом и лежит в `apps/bot/.env`,
который в `.gitignore`), так что публичность репозитория не раскрывает
ничего чувствительного.

Настройки репозитория на GitHub → **Pages** → Source: **Deploy from a
branch** → Branch: `main`, папка `/docs` → Save. Через минуту сайт будет
доступен по адресу вида `https://<аккаунт>.github.io/<репозиторий>/` —
открывается с телефона в любое время, комп для этого не нужен.

Бот (`apps/bot`) остаётся локальным процессом — он должен быть запущен,
чтобы Telegram-ссылки долетали. Если хочешь, чтобы и он работал 24/7 без
компа, его можно задеплоить (например на Railway/Fly.io) — отдельная
задача, скажи, если понадобится.

## Полезное

- Все данные живут в самой таблице — можно спокойно сортировать,
  фильтровать, добавлять свои колонки прямо в Google Sheets, сайт при
  этом продолжит работать (он не трогает лишние колонки).
- Если у сайта не находится цена или фото — значит магазин не отдаёт ни
  JSON-LD `Product`, ни Open Graph теги. Правь строку прямо в таблице.
- Ссылка на таблицу и её содержимое доступны любому, кто узнает URL (не
  проиндексировано, но не защищено паролем) — это плата за то, что сайт и
  чтение полностью бессерверные.
