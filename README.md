# Каталог личных покупок

Google Таблица — единственное хранилище (нет своей БД). Три способа
добавить в неё товар:

1. **Приложение Claude на телефоне** — если в Claude подключён коннектор
   Google Sheets/Drive, можно прямо в чате кинуть ссылку/HTML товара и
   попросить Claude добавить строку в таблицу. Не требует ничего из этого
   репозитория — настраивается в самом приложении Claude (Settings →
   Connectors).
2. **Telegram-бот** — присылаешь ему ссылку, он сам открывает страницу и
   парсит название/цену/фото. Не работает на сайтах с защитой от ботов
   (Cloudflare и т.п.) — тогда бот попросит ввести данные вручную.
3. **Браузерное расширение** — открываешь товар в своём браузере, жмёшь
   иконку расширения. Страница уже отрендерена (защита от ботов пройдена
   самим браузером), расширение читает данные прямо из DOM.

Сайт-каталог читает эту же таблицу напрямую и показывает всё плиткой
(фото/название/цена/ссылка на оригинал).

## Как это устроено

```
apps/
  bot/       — Telegram-бот (Telegraf). Парсит страницу на сервере; если
               сайт блокирует запрос — просит ввести данные вручную.
               Пишет строки прямо в Google Таблицу.
  web/       — сайт-каталог на Next.js. Читает товары из Google Таблицы
               при каждом заходе (без своей БД). Отдаёт POST /api/items
               для расширения.
  extension/ — расширение для Chrome/Chromium. Popup парсит открытую
               вкладку и шлёт данные на /api/items.
packages/
  scraper/  — серверный парсер title/price/image/site (для бота): сначала
              JSON-LD Product, потом Open Graph, потом <title>.
  sheets/   — вся работа с Google Таблицей: appendItemRow() (запись) и
              listItems() (чтение для сайта). Общий код для bot и web.
```

Раньше здесь была своя БД (Prisma/SQLite) с Sheets как дублирующим
логом. Отказались от неё, когда стало ясно, что комп не всегда включён:
теперь Google Таблица (облачная, всегда доступна) — источник правды, а не
просто копия.

## Установка

Нужен Node.js 18+.

```bash
npm install
```

### 1. Google Sheets (сервисный аккаунт) — обязательно, без этого не работает ничего

1. Зайди в [Google Cloud Console](https://console.cloud.google.com/), создай
   проект. Если попросит включить двухфакторную аутентификацию на
   Google-аккаунте — сделай это в [настройках безопасности аккаунта](https://myaccount.google.com/security)
   и вернись.
2. Включи **Google Sheets API** (APIs & Services → Library).
3. Создай сервисный аккаунт (APIs & Services → Credentials → Create
   Credentials → Service Account).
4. Открой созданный аккаунт → Keys → Add Key → JSON, скачай ключ.
5. Из JSON тебе нужны поля `client_email` и `private_key`.
6. Создай Google Таблицу (можно пустую, [sheets.new](https://sheets.new) —
   код сам создаст вкладку "Items" и заголовки при первой записи/чтении).
   Открой доступ на **редактирование** для email из `client_email`
   (кнопка «Поделиться»).
7. ID таблицы — часть ссылки: `https://docs.google.com/spreadsheets/d/ЭТОТ_ID/edit`.

### 2. Telegram-бот

Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получишь `BOT_TOKEN`.

### 3. Переменные окружения

```bash
cp apps/bot/.env.example apps/bot/.env
cp apps/web/.env.example apps/web/.env
```

В обоих файлах впиши:

- `GOOGLE_SHEETS_ID`, `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY`
  — из шага 1 (значения одинаковые в обоих `.env`).
- `apps/bot/.env` — ещё `BOT_TOKEN` из шага 2.
- `apps/web/.env` — ещё `EXTENSION_API_KEY`, любая случайная строка:
  ```bash
  node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
  ```

### 4. Запуск

```bash
npm run bot:dev   # в одном терминале
npm run web:dev   # в другом
```

Открой http://localhost:3000 — должен быть пустой каталог. Пришли боту в
Telegram ссылку на любой товар — он появится на сайте (сайт читает
таблицу при каждом запросе, просто обнови страницу).

### 5. Браузерное расширение (для сайтов, которые блокируют бота)

1. Открой `chrome://extensions` (или `edge://extensions`).
2. Включи **Режим разработчика** (переключатель справа сверху).
3. **Загрузить распакованное расширение** → выбери папку `apps/extension`.
4. Иконка расширения появится на панели — правой кнопкой по ней → **Параметры**.
5. Впиши:
   - **Адрес сайта каталога** — `http://localhost:3000` (или боевой адрес
     после деплоя на Vercel).
   - **API-ключ** — тот самый `EXTENSION_API_KEY` из `apps/web/.env`.
6. Сохрани. Теперь на странице товара жми на иконку расширения,
   проверяй/поправляй название-цену-фото и жми «Добавить в каталог».

Расширение просит доступ ко всем сайтам (`host_permissions`) — это
ожидаемо: сайт заранее не известен. Расширение не публикуется в Chrome
Web Store, работает только у тебя как «распакованное».

### 6. Деплой сайта на Vercel (чтобы каталог был доступен с телефона без включённого компа)

1. Залей репозиторий на GitHub (или GitLab/Bitbucket).
2. Зайди на [vercel.com](https://vercel.com) → New Project → выбери репозиторий.
3. **Root Directory**: укажи `apps/web` (это монорепо, сайт лежит не в корне).
4. В Environment Variables добавь те же переменные, что в `apps/web/.env`:
   `GOOGLE_SHEETS_ID`, `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY`,
   `EXTENSION_API_KEY`.
5. Deploy. Получишь постоянный адрес вида `https://твой-проект.vercel.app` —
   открывается с телефона в любое время, комп для этого не нужен.
6. В настройках расширения (шаг 5 выше) поменяй адрес сайта на этот URL.

Бот (`apps/bot`) остаётся локальным процессом — он должен быть запущен,
чтобы Telegram-ссылки долетали. Если хочешь, чтобы и он работал 24/7 без
твоего компа, его тоже можно задеплоить (например на Railway/Fly.io) —
скажи, если нужно, сделаем отдельно.

## Полезное

- Если у сайта не находится цена или фото — значит магазин не отдаёт ни
  JSON-LD `Product`, ни Open Graph теги. Правь строку прямо в Google
  Таблице — сайт сразу подхватит изменения.
- Все данные живут в самой таблице — можно спокойно сортировать,
  фильтровать, добавлять свои колонки прямо в Google Sheets, сайт при
  этом продолжит работать (он не трогает лишние колонки).
