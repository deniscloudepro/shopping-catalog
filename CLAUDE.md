# Каталог покупок — инструкция для Claude

## Когда пользователь присылает товар (ссылку, .mht/.html, скриншот или текст)

Добавь его в каталог и сразу задеплой — без бота и без Google Таблицы:

1. `npm install` (если ещё не ставил в этой сессии).
2. Добавь товар в `docs/items.json` одним из способов:
   - ссылка: `npx tsx scripts/add-item.ts '<url>'` (многие магазины
     блокируют запросы из песочницы — тогда попроси .mht или используй
     `--json`);
   - сохранённая страница: `npx tsx scripts/add-item.ts <путь к .mht/.html>`;
   - скриншот/текст: прочитай данные сам и вызови
     `npx tsx scripts/add-item.ts --json '{"title":"…","price":83190,"currency":"KZT","url":"…","imageUrl":"…"}'`.
   Проверь вывод: название без SEO-хвоста, цена актуальная (не зачёркнутая),
   `imageUrl` — прямая публичная ссылка на картинку. Повторная ссылка на тот
   же товар обновляет запись, а не дублирует её.
3. Закоммить и запушь **в `main`** — это и есть деплой (GitHub Pages
   публикует `/docs` из `main`, обновление появляется через 1–2 минуты).
   Пользователь явно разрешил пушить товары в `main` напрямую.
4. Ответь коротко: что добавлено (название, цена, ссылка) и что сайт
   обновится через пару минут.

Фото, присланное файлом, в каталог не положить: нужна публичная ссылка на
картинку (например `og:image` со страницы товара).

## Устройство
- `docs/` — статичный сайт; читает `docs/items.json` и (если доступна)
  Google Таблицу, показывает всё вместе по дате.
- `packages/scraper` — парсер товара из HTML (JSON-LD → Open Graph →
  `<h1>`/видимая цена) и распаковка .mht.
- `apps/bot`, `apps/extension`, `google-apps-script` — старые способы
  добавления через Google Таблицу, продолжают работать.
